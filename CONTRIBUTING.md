# Contributing

Thanks for considering a contribution.

## Good first changes

- Improve accessibility, responsive layout, copy clarity, or public links.
- Keep the site static and easy to inspect.
- Avoid build steps unless they remove real maintenance cost.

## Local validation

Open `index.html` in a browser and check desktop, mobile width, keyboard navigation, language toggle, public repo links, and the 404 page.

## Pull requests

- Keep public claims accurate and verifiable.
- Do not add tracking scripts, paid assets, private customer data, API keys, or production credentials.
- Keep the page usable without a build step.
