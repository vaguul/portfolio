# Roadmap

This roadmap keeps the public portfolio honest, small, and verifiable.

## Current focus

- Keep public project claims linked to real repositories or releases.
- Improve accessibility, responsive layout, and link behavior.
- Keep the site static, dependency-free, and easy to inspect.
- Keep Zemiax wording accurate as a personal software studio.

## Good first issues

- Add compact project case studies with public links.
- Improve mobile spacing and keyboard navigation if regressions appear.
- Keep sitemap, robots, and 404 page aligned with the live GitHub Pages URL.

## Later

- Add a short changelog if the portfolio starts shipping visible content releases.
- Add screenshots only when they improve project clarity and remain lightweight.
